## 🔄 Pembaruan & Perubahan Jobsheet 03

| Jenis Perubahan                    | Deskripsi                                                                                                                                             |
| :--------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 📱 **Penambahan Meta Viewport**    | Menambahkan `<meta name="viewport" content="width=device-width, initial-scale=1">` agar tampilan website dapat menyesuaikan ukuran layar perangkat. |
| 🍔 **Penambahan Navbar Hamburger** | Menambahkan menu hamburger pada navbar untuk mempermudah navigasi terutama pada perangkat dengan ukuran layar kecil seperti tablet dan mobile.        |
| 📊 **Tabel Dapat Di-scroll**       | Menambahkan fitur scroll horizontal pada tabel agar data tetap dapat dibaca dengan baik ketika ukuran tabel melebihi lebar layar.                     |
| 📐 **Responsive Design**           | Menyesuaikan tampilan website agar responsif dan nyaman digunakan pada berbagai perangkat, mulai dari desktop, tablet, hingga mobile.                 |

## ✨ Hasil & Dampak Penerapan CSS
Penerapan CSS dan fitur responsive membuat website menjadi lebih mudah digunakan. Tampilan navbar dapat menyesuaikan perangkat dengan adanya menu hamburger, sedangkan tabel dapat di-scroll sehingga data tetap dapat ditampilkan dengan baik pada layar yang lebih kecil. Dengan penerapan responsive design, website dapat digunakan dengan nyaman pada perangkat desktop, tablet, maupun mobile.
